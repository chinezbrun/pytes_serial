CHANGELOG
=========

All notable changes to pytes-serial are documented in this file.

----------------------------------------------------------------

Version 1.0.0 | 2026-04-09 
--------------------------

Deprecated:
- event_monitoring functionality removed.

Removed:
- Dynamic event configuration via events_config.json.
- Built-in power and system event mapping override logic.
- Auto-generation of events_config.json.

Changed:
- Simplified codebase by removing event monitoring components.
- Configuration cleanup (removed unused event-related settings).

----------------------------------------------------------------

Version 0.9.1 | 2026-02-23
--------------------------
Added:
- Periodic full state refresh.
- Retained publishing for critical sensors (system and battery level) to prevent
  stale values after Home Assistant or MQTT reconnects.

Fixed:
- System sensors could become "unknown" after Home Assistant restarts during long
  periods of unchanged data (issue #34).

Changed:
- Workaround for firmware versions reporting event values in either decimal or
  hexadecimal format (issue #44).
- Minor cosmetic changes.

----------------------------------------------------------------

Version 0.9.0 | 2025-10-18
--------------------------
Added:
- Support for reading event definitions from events_config.json.
- Automatic creation of events_config.json if it does not exist.

Fixed:
- Bug causing a variable number of items in the bat[] list (issue #43).

Changed:
- Improved event logging and text handling in check_events().

Notes:
- Backward compatible.
- No external dependencies added.
- Version published.

----------------------------------------------------------------

Version 0.8.0 | 2024-11-07
--------------------------
Added:
- Option to select levels of detail for cell monitoring.

Changed:
- Code refactoring.

----------------------------------------------------------------

Version 0.7.4 | 2024-08-14
--------------------------
Fixed:
- System sensors becoming "unknown" after Home Assistant restart (issue #34).

----------------------------------------------------------------

Version 0.7.3 | 2024-07-21

Fixed:
- Error and warning codes logging.

Changed:
- Updated requirements.txt.

----------------------------------------------------------------

Version 0.7.2 | 2024-05-01
--------------------------
Fixed:
- Console display for MQTT discovery progress percentage.

Changed:
- General cleanup.

Improved:
- MQTT publishing optimized to reduce unnecessary traffic.

----------------------------------------------------------------

Version 0.7.1 | 2024-04-28

Changed:

Version 0.7.0 | 2024-04-14

Added:

Changed:

Notes:

Version 0.6.2 | 2024-03-26

Fixed:

----------------------------------------------------------------

Version 0.6.1 | 2024-03-26
--------------------------
Fixed:

----------------------------------------------------------------

Version 0.6.0 | 2024-03-26
--------------------------
Added:
- Custom Home Assistant device name via configuration file
  (e.g. pytes, pytesone, pytestwo, pylon) (issue #20).

Fixed:
- Incorrect 100% SOC display in log files (issue #19).
- Sensor nickname display in Home Assistant (issue #21).

Changed:
- Renamed JSON field for better alignment with Pylon (pytes -> devices).

----------------------------------------------------------------

Version 0.5.0 | 2023-08-05
--------------------------
Added:
- Configurable logging level.
- Log size and backup count configurable via configuration file.
- Monitoring of power_events, bat_events, and sys_fault.
- Cell detail logging in battery_events.log when selected events occur.
- Script events logging in pytes_serial.log.
- Total number of events since startup reported in the serial_stat section
  of the JSON output.

Deprecated:
- event.log file.

----------------------------------------------------------------

Version 0.4.0 | 2023
--------------------
Added:
- Serial statistics reported in JSON output and published to MQTT.

Changed:
- Parsing loop refactored for improved flexibility.
- Serial read/write separated from parsing loop.
- Reading frequency limited to a minimum of 10 seconds to prevent BMS overload.
- Encoding switched to latin-1.
- Reverted to ASCII encode/decode.

Improved:
- Logging (main loop, parsing_serial, serial initialization).
- Serial reading speed and round-trip performance.
- Error handling in read/write loops.

----------------------------------------------------------------

Version 0.3.5 | 2023-02-26
--------------------------
Changed:
- statistics() now rounds voltage and current values to one decimal.
- mqtt_discovery() enhanced with state class support.
