CHANGELOG
=========

All notable changes to pytes-serial are documented in this file.

2.0.0 | 2026-09-05
- Consolidated PWR parsing using a single `pwr` command.
- Improved PWR and BAT invalid-data retry handling.
- Removed deprecated status/event fields and obsolete event counters.
- Updated MariaDB schema for v2.x.
- Improved MQTT handling of incomplete previous cell data.
- Removed obsolete code and diagnostics.
- Internal code cleanup and function naming alignment.

1.1.1 | 2026-08-23
- Improved serial recovery and retry mechanism, reducing false recovery activations.
- Fixed battery, power and system event total counters.
- Maintained backward compatibility.

1.1.0 | 2026-07-13
- Improved serial communication reliability and diagnostics.
- Added support for additional Pytes and Pylontech firmware, including improved battery data parsing (#47 - @001Tycoon).
- Added MQTT display precision for Home Assistant sensors.

1.0.1 | 2026-07-10
- Added suggested display precision to MQTT Discovery sensors.
- Added support for Pylontech US3000D batteries.

1.0.0 | 2026-04-09
- Removed event_monitoring functionality.
- Removed dynamic event configuration via events_config.json and its auto-generation.
- Removed built-in power and system event mapping override logic.
- Cleaned unused event-related configuration and code.

0.9.1 | 2026-02-23
- Added periodic full state refresh.
- Retained critical sensor publishing to prevent stale Home Assistant/MQTT values after reconnects.
- Fixed system sensors becoming `unknown` after Home Assistant restarts (#34).
- Added workaround for firmware reporting event values in decimal or hexadecimal format (#44).

0.9.0 | 2025-10-18
- Added events_config.json support and automatic creation.
- Fixed variable item count in the bat[] list (#43).
- Improved event logging and text handling in check_events().
- Maintained backward compatibility with no new external dependencies.

0.8.0 | 2024-11-07
- Added selectable cell monitoring detail levels.
- Refactored code.

0.7.4 | 2024-08-14
- Fixed system sensors becoming `unknown` after Home Assistant restart (#34).

0.7.3 | 2024-07-21
- Fixed error/warning code logging and missing sys_error log entry.
- Updated requirements.txt.

0.7.2 | 2024-05-01
- Fixed MQTT discovery progress display.
- Optimized MQTT publishing to reduce unnecessary traffic.
- General cleanup.

0.7.1 | 2024-04-28
- Fixed Pylontech parsing_bat() handling.
- Split MQTT payloads for better performance.

0.7.0 | 2024-04-14
- Added cell monitoring.
- Refactored MQTT discovery and improved performance.
- Updated pytes_serial.cfg.
- Maintained backward compatibility.

0.6.2 | 2024-03-26
- Fixed reported 100% CPU load issue.

0.6.1 | 2024-03-26
- Fixed missing current values after Pytes firmware update.

0.6.0 | 2024-03-26
- Added configurable Home Assistant device name (#20).
- Fixed incorrect 100% SOC display in logs (#19).
- Fixed sensor nickname display in Home Assistant (#21).
- Renamed JSON field from `pytes` to `devices`.

0.5.0 | 2023-08-05
- Added configurable logging level, log size and backup count.
- Added monitoring of power_events, bat_events and sys_fault.
- Added battery event details and script event logging.
- Added total event counters to JSON serial_stat.
- Deprecated event.log.

0.4.0 | 2023
- Added serial statistics to JSON and MQTT.
- Refactored parsing loop and separated serial read/write from parsing.
- Limited reading frequency to a minimum of 10 seconds.
- Improved serial reading, round-trip performance, logging and error handling.
- Updated serial encoding handling.

0.3.5 | 2023-02-26
- Rounded voltage and current statistics to one decimal.
- Added state class support to MQTT Discovery.
