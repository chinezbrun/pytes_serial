config file sections explained

[logging]
This section allows you to configure the logging level from DEBUG to ERROR.
According to Python logging levels, the order is: DEBUG < INFO < WARNING < ERROR.
For example, selecting logging.INFO will record INFO, WARNING and ERROR messages.

One log file is created:
pytes_serial.log -- PytesSerial application messages are logged here.

The maximum log file size and the number of backup files are configurable.


[cells_monitoring]
This section allows you to activate / deactivate / configure the 'cells monitoring' feature.

if cells_monitoring = true
-- Cell monitoring is activated. Sensors for cell parameters will be created in Home Assistant and cells will be monitored at the configured reading frequency.

if monitoring_level = low
-- Sensors for cell voltage will be created.

if monitoring_level = medium
-- Sensors for voltage, temperature, voltage status and statistics will be created.

if monitoring_level = high
-- Sensors for all available cell parameters will be created. This can generate a significant amount of data, especially with multiple batteries.
